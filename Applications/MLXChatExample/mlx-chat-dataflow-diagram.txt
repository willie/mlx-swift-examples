KEY COMPONENTS:
─────────────────
• PromptField.swift     - User input capture UI
• ChatViewModel.swift   - Business logic and state management  
• MLXService.swift      - Model loading and MLX integration
• Message.swift         - @Observable data model
• ConversationView      - Message display UI

ASYNC FLOW:
───────────
1. User action triggers async Task
2. MLX generates tokens as AsyncStream
3. ViewModel consumes stream chunks
4. @Observable properties update UI automatically
5. Users see real-time streaming response
